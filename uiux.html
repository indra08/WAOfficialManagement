07

Rules

Do & Don't

✓ Do
  • ▸Satu accent color per project — orange #f97316 untuk CTA, links, dan highlight kritis
  • ▸Neutral (abu) untuk semua text hierarchy — tidak ada warna lain di body text
  • ▸Void: #ffffff, Surface: #fafafa, Elevated: #f4f4f5, Border: #e4e4e7
  • ▸Glow/shadow hanya pada hover state aktif dengan tint orange-50 (#fff7ed)
  • ▸Border: #e4e4e7 — subtle tapi visible di background terang
✗ Don't
  • ▸Campur lebih dari 1 accent color dalam satu section
  • ▸Colored text untuk body paragraph panjang — neutral only
  • ▸Hover state terlalu bright (opacity >25%)
  • ▸Gunakan #e4e4e7 untuk background card — itu warna border, bukan fill
  • ▸Orange sebagai background section yang luas — hanya untuk highlight
  • ▸Border abu gelap (#a1a1aa ke atas) untuk dividers — noise visual

Touch & Focus
  • ▸Touch Target — minimum 44×44px untuk mobile interactive
  • ▸Button Min — 40px height
  • ▸Focus Ring — ring 3px orange-50 (#fff7ed) + border orange, outline-none
  • ▸Keyboard Nav — tab reach semua interactive element
  • ▸Spacing — minimum 8px gap antar interactive
